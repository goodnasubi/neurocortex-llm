## 判定

**A を採用**。検証では次の4条件で Phase B/C を比較する（Phase A は基底核を含まないため共通）。

1. `legacy`: 現行（`+0.01·value.mean()`）
2. `none`: value 項なし（B, 対照）
3. `td`: TD(0) critic のみ
4. `td_rpe`: TD(0) critic ＋ RPE によるアクター変調

**成功基準**: `td` または `td_rpe` で Phase A→B の劣化が `legacy` より有意に縮小し（3 seeds の平均差 > 2σ）、`none` と同等以上であること。`none` と同等にとどまる場合は「TD critic は害を除去するが言語モデル性能には寄与しない」と記録する。

## 結論

1. **劣化の原因は確定**: `legacy` の非有界な value 項を除くと（`none`）、A→B は +14.8% の劣化から −2.6% の改善に転じる。
2. **TD critic の勾配をバックボーンへ流すと害になる**: `td` は発散こそ止めるが、`legacy` と有意差がない。critic 回帰の勾配が言語表現を乱している。
3. **`td_sg`（勾配停止 TD critic）が採用候補**: `none` と同等の PPL を保ちながら、基底核の価値学習（腹側線条体）を保持している。成功基準の「`legacy` より有意に改善（差 0.79 > 2σ=0.31）、かつ `none` と同等以上」を満たす。ただし `none` を上回る寄与はない。
4. **|δ| による可塑性ゲーティングは有害**: `td_rpe` は +24%、`td_rpe_sg` は +1%。符号を無視したサプライズ重み付けは、難しい位置の CE を過大に重み付けするだけになっている。RPE をアクターに使うなら、符号付きの Go/NoGo（6.2節、直接路／間接路）として設計し直す必要がある（残課題）。

## 追検証: critic は価値を学習しているか（`step44_bg_critic_value_check.py`, `results/step44_bg_critic_ablation/value_check.json`）

Phase B、3 seeds、5 epochs。V_t と実現割引リターン G_t = Σ γ^k r_{t+k}（r=−CE, γ=0.9, 系列末で打ち切り）を検証データで比較した。「位置中心化 r」は位置ごとの平均を除いた相関で、打ち切りによる位置依存性を除き、内容に依存する価値の予測力を測る。

| mode | r（学習前→後） | 位置中心化 r（学習前→後） | 説明分散 | 平均 V / 平均 G |
|---|---|---|---|---|
| legacy | −0.001 → +0.193 | −0.022 → +0.280 | −17.95 | −2968.5 / −15.06 |
| td | −0.001 → +0.200 | −0.022 → +0.330 | +0.040 | −15.52 / −15.00 |
| td_sg | −0.001 → +0.109 | −0.022 → +0.180 | −0.008 | −13.71 / −13.66 |

- **td_sg の critic は価値を学習しているが、弱い**: 平均水準は正確で（V −13.71 対 G −13.66）、内容に依存する相関も +0.18 まで上がる。ただし勾配をバックボーンへ流す `td`（+0.33）より弱い。LM 用に最適化された特徴を読み出すだけなので、価値予測に特化した表現は作られない。「PPL を損なわない」と「価値表現の質」はトレードオフの関係にある。
- **説明分散がほぼ0になる主因は位置情報の欠如**: G の分散の大半は系列末での打ち切りによる位置依存性だが、バックボーン（Embedding＋TransformerEncoderLayer）には位置エンコーディングがなく、critic は位置を表現できない。
- **legacy は相関だけ見ると悪くないが、値の尺度が発散している**（平均 V −2969）。価値推定として機能していない。

### 残課題（追加）

- バックボーンに位置エンコーディングがない。これは基底核に限らず、検証用バックボーン全体の欠陥である。ステップ44.4 のフル規模実験のモデルに同じ欠陥があるかを確認する必要がある。
- td_sg の critic に専用の中間層（線条体側の表現）を持たせ、PPL を損なわずに価値表現を強化できるか。
