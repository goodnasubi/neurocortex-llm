# ステップ0: スパイキング基盤の立ち上げ — 実装と結果

本書は `docs/brain-structure-research.md` 12.6節ステップ0の実施記録である。対応する
設計判断は 12.3.1節（適応閾値LIF・二値スパイク・位置方向の膜電位）、12.5節（段階1の
実行基盤）、12.6.1節（識別テストの設計）、12.9節（整数スパイク数方式の棄却）、
12.10節（Python + PyTorch）、12.11節（WSL2のCPUで完結する規模）にある。

## 2. 実行方法

前提: WSL2 (Ubuntu 24.04) の venv（torch 2.14.0+cpu / numpy 2.5.3 / pytest）。GPUは使わない。

```bash
# テスト（29件）
python -m pytest tests/ -q

# 識別テスト テストA（主指標）
PYTHONPATH=src python -m neurocortex.experiments.run_identification --delay 16 --seeds 5 --steps 1500

# 遅延Nと漏れ係数βの掃引
PYTHONPATH=src python -m neurocortex.experiments.run_delay_sweep --seeds 3

# テストB（単層限定の確認）
PYTHONPATH=src python -m neurocortex.experiments.run_order --seeds 5

# 言語モデル副指標（合成コーパス。--data で任意テキスト）
PYTHONPATH=src python -m neurocortex.experiments.run_lm --steps 1500 --seq-len 64 --d-model 192
```

結果は `results/*.json`（と同名の `.log`）に保存される。

## 3. 識別テスト テストA（主指標）の結果

設定: 遅延 N=16、cue記号8種（チャンス 12.5%）、filler記号8種、系列長17、
d_model=64、2層、1500ステップ、バッチ64、学習率グリッド {1e-3, 3e-3, 1e-2}、5シード、
β=0.95 / θ=1.0 / κ=0.5 / λ=0.9 / arctanサロゲート α=2.0。
評価は各条件2048サンプル（チャンス+2σ = 13.96%）。

| 条件 | seed0 | seed1 | seed2 | seed3 | seed4 |
|---|---|---|---|---|---|
| **スパイキング版（N=16）** | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| **対照群＝階段関数（N=16）** | 0.1274 | 0.1348 | 0.1284 | 0.1279 | 0.1182 |
| 統制1: 対照群（N=0） | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| 統制1: スパイキング版（N=0） | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| 統制2: スパイキング版の膜電位持ち越しをゼロ化（N=16） | 0.1128 | 0.1313 | 0.1284 | 0.1250 | 0.1255 |

### 合格条件の判定（12.6.1節）

| 条件 | 判定 |
|---|---|
| N=16 でスパイキング版が90%以上、5シードすべて | **成立**（全シード100%） |
| 対照群がチャンス+2σ（13.96%）以内、5シードすべて | **成立**（11.8〜13.5%） |
| 統制1: 対照群が N=0 を解ける | **成立**（全シード100%） |
| 統制2: 膜電位ゼロ化でチャンス+2σまで低下 | **成立**（11.3〜13.1%） |
| → **総合判定** | **合格** |

補足:

- **統制3（学習予算の対称性）**: 両群は同一の `train_recall` を同一の `TrainConfig`・同一の
  学習率グリッド・同一シードで学習している。ベスト学習率は両群とも 1e-3 だったが、
  対照群はどの学習率でもチャンス（12.67〜12.73%）で、学習率の選択に結果は依存しない。
- **統制4（複数シード）**: 5シード。スパイキング版はばらつきゼロ（全て1.0000）、
  対照群の標準偏差は約0.006。
- **統制5（経路の監査）**: `tests/test_path_audit.py` が (a) 構文木上に位置を跨ぐ演算が
  存在しないこと、(b) モジュール型がホワイトリスト内であること、(c) **ヤコビアンによる
  動的検査**で「対照群は出力[i]が入力[i]にしか依存しない」「スパイキング版は過去にのみ
  依存し未来には依存しない」「膜電位の持ち越しを切ると位置間依存が完全に消える」ことを
  保証する。(c) は位置間経路が膜電位だけであることの機械的な証明になっている。
- **発火率**: スパイキング版は 5.8〜9.1%（層1が約8%、層2が約6%）。0%にも100%にも
  張り付いていない。

## 4. 遅延Nと漏れ係数βの掃引（12.6.1節の副次条件）

スパイキング版のみ、3シードの平均正答率（1000ステップ、lr=3e-3、チャンス12.5%）。

| β | 保持時間の目安 1/(1-β) | N=4 | N=8 | N=16 | N=32 | N=64 |
|---|---|---|---|---|---|---|
| 0.5 | 2.0 | 1.0000 | 0.9170 | 0.7119 | 0.2065 | 0.1169 |
| 0.7 | 3.3 | 1.0000 | 0.9993 | 0.7467 | 0.1333 | 0.1209 |
| 0.9 | 10.0 | 1.0000 | 1.0000 | 1.0000 | 0.9341 | 0.1346 |
| 0.95 | 20.0 | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 0.5125 |
| 0.99 | 100.0 | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 0.9964 |

**解釈**: 正答率が崩れる遅延は β とともに単調に伸び、β=0.5 では N=32 で、β=0.9 では
N=64 で、β=0.99 では N=64 でもまだチャンスに落ちない。これは「膜電位の指数的な漏れが
保持時間を決めている」というメカニズムの理解と整合しており、12.6.1節が求めた
「βから予測される保持時間との整合」を満たす追加証拠になる。

ただし定量的には、崩壊点は 1/(1-β) の値そのものよりかなり大きい遅延で起きる
（β=0.5 は目安2.0に対し N=8 でも91.7%）。1/(1-β) は単一ニューロンの時定数の目安であり、
実際には64本のニューロンが分散して符号化し、層を重ねて増幅しているため、
オーダーの傾向は一致するが定数倍のずれがある。12.6.1節の「おおよそ」という記述の
範囲内と判断する。

なお12.6.1節「失敗時の扱い」が定めるβ5点掃引はここで実施済みであり、打ち切り基準
（5点全滅）には該当しない。

## 5. 識別テスト テストB（確認用・単層限定）

構成: 埋め込み → 因果的線形アテンション1層 → 活性化 → 出力。位置エンコーディングなし。
課題: 記号AとBが系列（長さ16）中に1回ずつ現れ、どちらが後かを答える（チャンス50%）。

| 条件 | seed0 | seed1 | seed2 | seed3 | seed4 |
|---|---|---|---|---|---|
| スパイキング版 | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| 対照群（階段関数） | 0.5625 | 0.5571 | 0.5786 | 0.5591 | 0.5698 |
| スパイキング版の膜電位ゼロ化 | 0.5625 | 0.5571 | 0.5786 | 0.5615 | 0.5557 |

**対照群の 56% は偶然ではなく、完全に説明がつく**: 系列長16でA・Bのうち片方が最終位置に
来る確率は 2/16 = 12.5% であり、その場合は最終位置のトークンを見るだけで自明に正解できる。
したがって順序情報を一切使えない解法の期待値は 0.5 + 0.125 × 0.5 = **0.5625** であり、
実測値と一致する。つまり対照群は「順序を判別できる割合は0」である。

膜電位ゼロ化した場合の値が対照群とほぼ厳密に一致する点も、12.6.1節が述べた
「単層の線形アテンション状態は順序に不変」という根拠が実装上も成り立っていることを示す。
12.6.1節の限定の通り、これは単層構成でのみ成立する補助的な確認であり、
主張の重みはテストAに置く。

## 6. 言語モデル部分（副指標・健全性チェック）

構成: 文字レベル、d_model=192、3層、4ヘッド、系列長64、**1,355,712パラメータ**
（12.11節の「1〜3Mパラメータ」の範囲内）。3モデルともパラメータ数は完全に同一
（`tests/test_tasks_and_lm.py` で機械的に検査）。1000ステップ、バッチ16、AdamW、
lr=2e-3（コサイン減衰）。

- `spiking`: 因果的線形アテンション + ALIF（膜電位は位置方向）
- `step`: 同構成でニューロンを階段関数に置き換えたもの
- `dense`: 同規模の密なTransformer（softmaxアテンション + GELU）

### 合成コーパス（既定・外部ダウンロード不要）

語彙28文字、学習358,411文字 / 検証39,823文字。

| モデル | パラメータ数 | 検証PPL | 学習時間(CPU) | 発火率（層ごと） |
|---|---|---|---|---|
| spiking | 1,355,712 | **1.3727** | 399秒 | 0.052 / 0.113 / 0.046 / 0.141 / 0.058 / 0.183 |
| step（階段） | 1,355,712 | 1.3653 | 338秒 | 0.407 / 0.084 / 0.399 / 0.125 / 0.418 / 0.208 |
| dense（密） | 1,355,712 | **1.3625** | 81秒 | — |

- **発火率**: スパイキング版は 4.6〜18.3%。0%にも100%にも張り付いていない（12.6節の副指標を満たす）。
- **発散の有無**: 3モデルとも `diverged: false`。勾配ノルムは全期間 0.2〜0.7 の範囲で安定。
- **小バッチへの過学習**: 8系列を300ステップ繰り返すと spiking 3.569→0.0057、
  step 3.585→0.0057、dense 3.586→0.0056。3モデルとも問題なく過学習でき、
  最適化経路に異常はない。
- **速度**: スパイキング版は密なベースラインの約5倍の時間がかかる。位置方向の逐次ループ
  （膜電位の更新と線形アテンションの状態更新）が原因であり、12.3.1節が「実装上の代償」
  として予告していた通りの挙動である。

**重大な留保**: 合成コーパスは規則的すぎてPPLが1.36前後まで下がり、3モデルの差
（1.3625〜1.3727）が誤差の範囲に収まってしまう。この条件では言語モデリング性能の比較は
情報を持たない。そもそも12.6節が主指標を識別テストに変えた理由がこれであり
（「PPLが同等であってもスパイキングである必然性を何も示さない」）、副指標としては
「発散しない・過学習できる・発火率が飽和しない」という健全性の確認に意味を限定する。

### 実テキスト（`docs/brain-structure-research.md` を `--data` で指定）

語彙1,004文字（日本語のため文字種が多い）、学習36,656文字 / 検証4,072文字。
パラメータ数は語彙が大きい分 1,730,496（3モデルとも同一）。

| モデル | 検証PPL | 学習時間(CPU) | 発火率（層ごと） |
|---|---|---|---|
| spiking | **28.45** | 400秒 | 0.092 / 0.114 / 0.363 / 0.085 / 0.141 / 0.126 |
| step（階段） | **22.33** | 353秒 | 0.378 / 0.142 / 0.332 / 0.145 / 0.378 / 0.123 |
| dense（密） | **27.78** | 93秒 | — |

**この条件ではスパイキング版が3モデル中もっともPPLが高い（悪い）**。密なベースラインに
0.67、階段版に6.12 及ばない。都合よく解釈せずそのまま記録する。

考えられる要因（いずれも本実験では切り分けていない）:

1. 二値スパイク {0, 1} は階段関数の5値（0, 0.25, …, 1）より1位置あたりの情報量が少なく、
   語彙1,004の予測には不利に働きうる。12.6.1節は「階段関数はReLUより表現力が低い」と
   書いているが、**二値スパイクと比べれば階段関数のほうが表現力は高い**。
   識別テストでは「それでも階段版は解けない」ことを示すので主張はむしろ強くなるが、
   言語モデリング性能では逆に不利な方向に働く。
2. コーパスが36,656文字と小さく、1.7Mパラメータのモデルには過学習しやすい条件である。
3. 12.7節が予告した通り、サロゲート勾配は勾配が疎・ノイジーになるため、同じ1000ステップ
   では収束が遅い可能性がある（学習曲線は3モデルとも単調に下がり続けており、
   打ち切り時点で収束していない）。

12.7節「戦略上の前提（スケールでは勝たない）」の通り、本プロジェクトの主張は
言語モデリング性能ではなくテストAに置かれる。この結果はその前提と矛盾しないが、
「スパイキング版は言語モデリング性能では劣りうる」ことの具体的な数値として残しておく。

## 7. テスト（常設の自己検証）

`python -m pytest tests/ -q` で34件すべて通過する。12.7節「スパイキングであることの
自己検証の必要性」に対応し、以下を常設で検査している。

- **スパイク出力が厳密に {0, 1} であること**、順伝播が厳密なHeavisideであること
- **サロゲート勾配が流れ、かつSTEではないこと**（勾配が x=0 付近で最大の単峰形になり、
  裾では1割未満に減衰することを確認。STEなら一定値になる）
- **ALIFが本当に時間ダイナミクスを持つこと**: 定常入力に対して出力が位置ごとに変化する。
  12.9節で棄却された方式はここで定常応答を返す
- **12.9節の検証の再現**: `StepActivation` が n_steps+1 値の単調な階段関数に厳密に退化し、
  折れ目だけから再構成した階段関数とランダム入力5万点で完全一致すること。
  さらに漏れも適応もない場合に `clamp(floor(4I)/4, 0, 1)` と**厳密に一致**すること
- **ソフトリセット（減算型）であってハードリセットでないこと**
- **統制5の経路監査**（第3節参照）と、監査自体が実際の違反（`attention.py`）を
  検出できることの確認
- 課題生成の健全性（cue/fillerが互いに素、fillerからラベルが推定できない、
  遅延がバッチ内でランダムであること）
- 言語モデルの因果性、3モデルのパラメータ数の一致、規模が1〜3Mに収まること

## 8. 実装中に判明した設計上の問題・ドキュメントとの食い違い

1. **「遅延N」の定義が12.6.1節では一意に定まらず、統制1が成立しない構成があった**。
   課題を `[cue] [filler × N] [query]` と素直に読むと、N=0 でも cue と解答位置（query）が
   別位置になるため、位置間経路を持たない対照群は N=0 でも原理的に解けない。これでは
   統制1（「対照群が N=0 の課題は解けること」）が永久に成立しない。実装では
   **N を「cue位置から解答位置までの距離」と定義し直し、N=0 では解答位置そのものを
   cue にした**。これで統制1は全シード100%で成立する。12.6.1節にこの定義を明記すべき。
   （最初の実装では旧定義で走らせ、統制1が5シードとも12%前後＝チャンスになった。
   原因は対照群の能力不足ではなく課題定義の側にあった。）
2. **表現力の交絡の向きが12.6.1節の記述と逆である**。同節は階段関数を使う理由を
   「ReLUではなく階段関数を使うことで表現力の差という交絡を排除」と説明するが、
   実際には二値スパイク {0,1} より階段関数の5値のほうが1位置あたりの表現力は**高い**。
   識別テストにとってはハンデを背負った側が勝つので主張は強くなるが、
   言語モデリング性能の比較では逆にスパイキング版に不利に働く（第6節の実測の通り）。
   「表現力の差を排除」ではなく「表現力で不利な側が勝つ構成」と書くのが正確である。
3. **テストBの対照群はチャンス50%には落ちない**。系列長16でA/Bの片方が最終位置に来る
   確率2/16のぶん、順序を全く使えなくても期待値56.25%になる。12.6.1節の予測
   （チャンスレベル）は、この自明な解法を差し引いてから読む必要がある。
4. **速度の代償は実測で約5倍**（言語モデル、系列長64、CPU）。12.3.1節の予告通りだが、
   12.11節のJetson Nanoでカーネル融合が使えないことと合わせると、系列長を64〜128に
   抑える制約は緩和策ではなく必須条件である。
5. **`ALIFNeuron` の `carry_membrane` フラグは統制2の実装として十分に強い**。
   重みに一切触れず、ヤコビアンで「位置間依存が完全に消える」ことまで検証できる
   （`tests/test_path_audit.py`）。同一モデル内の因果操作として12.6.1節が期待した
   性質を満たしている。

## 9. ステップ0の結論

**12.6節ステップ0の合格条件「時間ダイナミクスが実際に機能していること」は満たされた。**

- 主指標（テストA）の4条件すべてが5シードで成立した。膜電位だけが位置間経路である構成で
  遅延16の想起を100%解き、12.9節で等価性が証明された階段関数に置き換えるとチャンスに
  落ち、同じモデルの膜電位の持ち越しだけを推論時に切ってもチャンスに落ちる。
  位置間経路が膜電位だけであることはヤコビアンで機械的に検証済みである。
- βの掃引は打ち切り基準（5点全滅）に該当せず、保持時間とβの関係はメカニズムの理解と
  整合する。
- 副指標は「発散しない・小バッチに過学習できる・発火率が飽和しない」を満たす一方、
  言語モデリング性能は密なベースラインに対して同等〜やや劣る（実テキストでPPL 28.45 対 27.78）。

**未実施**: 12.6節の副指標のうち Jetson Nano 上での J/token 実測（12.11節）は本ステップでは
行っていない。12.1節の「常に稠密演算」という限界への反論を数値で裏づける唯一の経路である
ため、次の作業として残っている。
