# NeuroCortex-LLM (大脳新皮質-LLM)

## プロジェクトの目的

人間の脳と同じように、脳を模擬した環境で、ニューロン＆シナプス結合し、人間の脳と同じ構造を持つLLMを作ってみたい。

現行のTransformerベースのLLMとは異なるアプローチとして、実際の人間の脳の構造（ニューロン・シナプス・皮質コラム・海馬・大脳基底核・小脳などの専門化された領域とその結合様式）を出発点に、脳型（brain-inspired）のアーキテクチャを持つ言語モデルの設計を検討する。

## リポジトリの構成

- [`docs/brain-structure-research.md`](docs/brain-structure-research.md) — 基礎調査メモ。人間の脳の構造・スケール・学習則に関する定量データと、既存の脳型言語モデル研究の整理

## 調査済みトピック

1. 脳全体のスケール（ニューロン数・シナプス数・領域ごとの実効パラメータ試算）
2. 大脳皮質の構造（層構造・皮質コラム・機能分化）
3. 細胞タイプ（ニューロン・グリア細胞）
4. シナプスと可塑性の基本原理
5. 既存の「脳型」大規模言語モデル研究（SpikingBrain等）
6. 海馬・大脳基底核・小脳の情報処理アルゴリズム（記憶形成・強化学習・運動制御）
7. コネクトーム（脳の配線図）の実測データとネットワーク構造（リッチクラブ、スモールワールド性）
8. STDP・BCM則の数式的定式化と既存SNNフレームワーク（Brian2, NEST, snnTorch等）
9. Numenta HTM（Hierarchical Temporal Memory）— 皮質コラム理論に基づくアーキテクチャ
10. ニューロモーフィックハードウェア（Loihi 2, NorthPole等）

各トピックの詳細な内容と出典は [`docs/brain-structure-research.md`](docs/brain-structure-research.md) を参照。

## 今後の調査候補

- 海馬リプレイ／経験再生をLLMの継続学習・破局的忘却対策にどう応用できるか
- コネクトームのリッチクラブ／モジュール構造を模したTransformer結線トポロジーの具体的設計案
- より生物学的に妥当な可塑性則（スパイク三つ組STDP等）の詳細と実装例
- HTM/サウザンド・ブレインズ理論の実装と実タスクでの性能評価
- スパイキングLLMとニューロモーフィックチップの共設計（co-design）
- ここまでの調査を踏まえた独自アーキテクチャ設計案の検討（統合フェーズ）
