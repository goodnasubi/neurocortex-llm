# NeuroCortex-LLM (大脳新皮質-LLM)

## プロジェクトの目的

人間の脳と同じように、脳を模擬した環境で、ニューロン＆シナプス結合し、人間の脳と同じ構造を持つLLMを作ってみたい。

現行のTransformerベースのLLMとは異なるアプローチとして、実際の人間の脳の構造（ニューロン・シナプス・皮質コラム・海馬・大脳基底核・小脳などの専門化された領域とその結合様式）を出発点に、脳型（brain-inspired）のアーキテクチャを持つ言語モデルの設計を検討する。

## 独自アーキテクチャ設計案（12章）の要点

- 単一の密なTransformerパイプラインではなく、機能分化した4モジュール（皮質バックボーン・海馬モジュール・基底核モジュール・小脳モジュール）をスパースな「ハブ潜在表現」経由で結合する構成
- スパイクベースの計算をオプションではなく設計の基礎に据える
- モジュールごとに異なる学習則を採用（皮質: 誤差逆伝播、海馬: 局所連想学習＋リプレイ、基底核: 方策勾配／TD学習、小脳: Widrow-Hoff局所誤差則）
- 実装は3段階（snnTorch/GPUでのプロトタイピング → Brian2/NESTによる局所学習則の検証 → ニューロモーフィックハードウェアへの移植）
- 実装ロードマップは6ステップ（0. スパイキング基盤、1. 海馬モジュール、2. 基底核デュアル経路、3. 皮質ハブのスパース化、4. 小脳モジュール、5. STDP/BCM局所則の導入）

## 今後の調査候補

- 海馬リプレイ／経験再生をLLMの継続学習・破局的忘却対策にどう応用できるか
- コネクトームのリッチクラブ／モジュール構造を模したTransformer結線トポロジーの具体的設計案
- より生物学的に妥当な可塑性則（スパイク三つ組STDP等）の詳細と実装例
- HTM/サウザンド・ブレインズ理論の実装と実タスクでの性能評価
- スパイキングLLMとニューロモーフィックチップの共設計（co-design）
- 12章の独自アーキテクチャ設計案のプロトタイプ実装（ステップ0: スパイキング基盤の構築）
